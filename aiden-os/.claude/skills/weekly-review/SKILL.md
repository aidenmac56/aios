---
name: weekly-review
description: Friday/Sunday review of results vs goals, and what to change. Use when he asks how the week went or for a review.
---

1. Gather real numbers only: videos published, views, booking clicks/calls (ask him for anything not in a
   connected tool; never estimate a metric as if it were measured).
2. Compare to `context/goals.md`. One line per metric: target, actual, on/off track.
3. Two or three changes for next week, each with the expected effect. Ask which to adopt.
4. Write the adopted changes into the relevant context file or skill, and log them in
   `decisions/YYYY-MM-DD-weekly-review.md`.
