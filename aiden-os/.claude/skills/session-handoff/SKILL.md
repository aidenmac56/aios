name: session-handoff
description: Summarize this session so a fresh one can pick up. Use before /clear, switching tools, or when he says "handoff".
---

Write a short handoff he can paste into a new session:
- **Goal** of this session
- **Done**: what was built or decided (file paths)
- **Decisions locked**
- **Open questions / deferred**
- **Next step**: the exact first action
Also save it to `archives/handoff-YYYY-MM-DD-HHMM.md`.
