---
name: thumbnail
description: Make YouTube thumbnail options for a script with Higgsfield. Use when a video script is ready or he asks for a thumbnail.
---

1. Read the script in `content/youtube/`. Pick the single strongest idea (a number, a problem, a before/after).
2. Generate 3 options with the higgsfield MCP `generate_image` (16:9): bold 3-5 word text, high contrast, one
   clear subject. If his face reference exists in Higgsfield (`list_characters`), use it; otherwise leave space
   for a cutout of him.
3. Save links/paths next to the script and ask which one he wants. Don't upload anything.
